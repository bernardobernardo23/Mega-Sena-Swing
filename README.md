# Mega Sena

## Sobre o Projeto
Este projeto foi desenvolvido como parte da avaliação da disciplina **Programação de Computadores II** da **UEPG**. O objetivo principal é criar uma aplicação para simulação de jogos da Mega-Sena utilizando a linguagem **Java** e a biblioteca **Swing** para a interface gráfica.

A aplicação permite que o usuário selecione o número de dezenas desejadas para seu jogo e, a cada nova solicitação, o valor do bilhete é ajustado automaticamente. Além disso, a lógica garante que os números sorteados não se repitam.

## Como Funciona
A aplicação possui uma interface gráfica com uma tela principal onde:
1. O usuário pode selecionar o número de dezenas desejado para o jogo.
2. A cada seleção, o valor do bilhete é ajustado automaticamente de acordo com a quantidade de dezenas escolhidas.
3. O sistema simula um sorteio de números, garantindo que eles não se repitam, para que o usuário tenha uma experiência realista de aposta na Mega-Sena.
4. O sistem ajusta a lista de números para a ordem crescente a cada requisição

### Funcionalidades
- **Seleção de Dezenas:** O usuário escolhe quantas dezenas quer para seu jogo (entre 6 e 15).
- **Ajuste Automático do Valor:** O valor do bilhete é alterado conforme o número de dezenas selecionado.
- **Geração de Números Aleatórios:** Os números sorteados são únicos, ou seja, não se repetem durante a simulação do jogo.
  
## Tecnologias Usadas
- **Java:** Linguagem principal utilizada para o desenvolvimento do projeto.
- **Java Swing:** Biblioteca gráfica usada para criar a interface do usuário.
